# 恶意 WiFi 检测 MVP — 需求规格说明

---

## v1.0 需求规格说明

### 项目概述
本项目旨在构建一个基于 Agent-based 架构的 MVP，通过模拟分析 WiFi 网络特征，检测潜在的个人信息窃取风险，并向用户发出红/黄/绿灯直观预警。

### 用户角色
- **普通用户**：点击一键扫描，查看周边 WiFi 安全评估报告

### 核心功能
1. **模拟 WiFi 扫描**：从本地 JSON 文件加载预设 WiFi 场景数据
2. **AI Agent 诊断**：通过规则引擎模拟安全专家分析，输出风险等级和诊断报告
3. **可视化预警**：使用 Streamlit 展示红/黄/绿灯卡片式的安全分析结果

### 验收标准
- [ ] 用户点击"一键扫描"按钮后可看到 WiFi 列表
- [ ] 选择某个 WiFi 后展示包含风险等级、意图分析、安全建议的诊断报告
- [ ] 高风险 WiFi 以红色错误卡片展示，中风险以黄色警告展示，低风险以绿色成功卡片展示
- [ ] JSON 文件缺失或格式错误时有友好的错误提示

### 边界与限制
- 禁止引入真实的网络流量抓包
- 禁止调用真实的大模型 API（如 OpenAI, LangChain）
- 所有数据来源于 `data/wifi_scenarios.json`
- 界面文本与代码注释保持中文

## v2.0 需求规格说明

### 项目概述
本项目旨在构建一个基于 Agent-based 架构的 MVP，通过模拟分析 WiFi 网络特征，检测潜在的个人信息窃取风险，并向用户发出红/黄/绿灯直观预警。

**v2.0 基于用户反馈迭代**，在 v1.0 核心流程基础上增强视觉直观性、交互明确性和用户参与感。

### 用户角色
- **普通用户**：点击一键扫描，查看周边 WiFi 安全评估报告，提交使用反馈

### 核心功能

#### v1.0 保留功能
1. **模拟 WiFi 扫描**：从本地 JSON 文件加载预设 WiFi 场景数据
2. **AI Agent 诊断**：通过规则引擎模拟安全专家分析，输出风险等级和诊断报告
3. **可视化预警**：使用 Streamlit 展示红/黄/绿灯卡片式的安全分析结果

#### v2.0 新增功能
4. **风险排序**：WiFi 列表默认按风险等级从高到低排列，高风险置顶
5. **风险筛选**：提供 全部 / 🔴高风险 / 🟡中风险 / 🟢低风险 四个筛选按钮
6. **风险标签**：每个 WiFi 前显示红/黄/绿风险图标，信号强度图标，无需点开即可感知风险
7. **显式诊断触发**：选择 WiFi 后需点击「开始诊断」按钮，报告才会更新，交互意图更明确
8. **诊断原因标签**：报告卡片内展示彩色原因标签（如"🔓 开放网络""🕵️ DNS劫持风险""🔗 Portal认证"），一目了然
9. **同名热点检测**：当存在相同 SSID 的 WiFi 时，列表显示 ⚠️同名 警告标记，防止恶意热点伪装
10. **黑名单管理**：高风险 WiFi 可加入黑名单，在列表中统一管理
11. **用户反馈收集**：页面底部提供反馈输入框，用户提交的建议保存至本地文件
12. **信号强度可视化**：根据 dBm 值显示不同信号图标（优秀/良好/较弱）

### 验收标准
- [ ] 用户点击"一键扫描"按钮后可看到 WiFi 列表，**列表按风险从高到低排序**
- [ ] 每个 WiFi 条目显示🔴🟡🟢风险图标 + 信号强度图标 + 加密方式
- [ ] 存在同名 SSID 时，列表顶部显示 ⚠️ 警告，同名条目标注标记
- [ ] 点击筛选按钮（全部/高/中/低）可过滤对应风险等级的 WiFi
- [ ] 选择某个 WiFi 后点击「开始诊断」，展示完整诊断报告卡片
- [ ] 报告卡片包含：风险等级标题、诊断原因标签（彩色 pill）、意图分析、安全建议
- [ ] 高风险报告卡片下方显示「加入黑名单」按钮，可加入/移出黑名单
- [ ] 黑名单区域展示已标记的 WiFi 详细信息（SSID、MAC、信道、加密）
- [ ] 用户反馈区可输入文字并提交，提交后显示成功提示
- [ ] JSON 文件缺失或格式错误时有友好的错误提示

### 边界与限制
- 禁止引入真实的网络流量抓包
- 禁止调用真实的大模型 API（如 OpenAI, LangChain）
- 所有数据来源于 `data/wifi_scenarios.json`
- WiFi 唯一标识使用 MAC 地址（而非 SSID），避免同名热点覆盖
- 界面文本与代码注释保持中文

## v3.0 需求规格说明

### 项目概述
v3.0 在 v2.0 基础上，新增黑名单备注、风险计数、WiFi 对比分析三大功能，进一步提升用户体验和决策支持能力。

### v3.0 新增功能
13. **黑名单备注**：加入黑名单时可添加 2-5 字备注标签（如"可疑热点"），备注持久化保存至 `data/blacklist_notes.json`，下次扫描后 WiFi 列表对应项显示备注标签
14. **风险筛选计数**：筛选按钮（全部/高/中/低）后显示对应风险 WiFi 数量，如"🔴 高风险 (2)"，方便用户快速感知区域安全态势
15. **WiFi 对比分析**：可选择两个 WiFi 进行并排对比，从风险等级、加密方式、信号强度、DNS 劫持风险、Portal 认证五个维度综合评估，给出综合评分（满分 100）和建议连接的 WiFi，解决用户在多个低/中风险 WiFi 间的选择困难

### 验收标准 (v3.0 新增)
- [ ] 高风险诊断报告下显示备注输入框（2-5字限制）和「加入黑名单」按钮
- [ ] 加入黑名单后，WiFi 列表对应项显示备注标签和已拉黑标记
- [ ] 黑名单管理区展示备注信息，移除黑名单时同步清除备注
- [ ] 刷新页面并重新扫描后，黑名单备注数据持久化保留
- [ ] 筛选按钮标签显示对应风险等级的网络数量，如"🟡 中风险 (2)"
- [ ] 页面下方显示「WiFi 对比分析」区域，可分别选择两个 WiFi 进行对比
- [ ] 对比结果包含综合评分（带差值）、五维度详细对比表（优胜方绿色高亮）
- [ ] 对比报告给出明确建议（建议连接 / 两者安全性相当）

### 边界与限制（同 v2.0）
- 禁止引入真实的网络流量抓包
- 禁止调用真实的大模型 API
- 所有数据来源于 `data/wifi_scenarios.json`
- 备注数据保存至 `data/blacklist_notes.json`
- 界面文本与代码注释保持中文

## v4.0 需求规格说明

### 项目概述
v4.0 为体验修复版本，解决 v3.0 遗留的三个交互缺陷：对比区域未扫描时不可见、黑名单刷新丢失、黑名单仅限高风险。

### v4.0 新增/修复
16. **对比区域始终可见**：未扫描时对比区域仍展示标题和提示文案"请先扫描周边 WiFi，扫描完成后可在此选择两个网络进行并排对比分析"，扫描后正常激活
17. **黑名单持久化**：黑名单 UID 列表随备注一同持久化——启动时从 `blacklist_notes.json` 的 keys 恢复，页面刷新后不再丢失
18. **全风险等级可拉黑**：移除高风险专属限制，任何风险等级的 WiFi 诊断后均可加入黑名单，黑名单管理区按实际风险等级显示对应图标

### 验收标准 (v4.0 新增/变更)
- [ ] 页面首次加载（未扫描）时，对比分析区域可见，显示提示文案
- [ ] 扫描后对比区域正常激活，提示文案替换为操作说明
- [ ] 加入黑名单后刷新页面并重新扫描，已拉黑 WiFi 仍显示标记
- [ ] 中风险、低风险 WiFi 诊断报告下均显示「加入黑名单」按钮
- [ ] 黑名单管理区 WiFi 条目使用实际风险图标，不再统一显示 🔴

### 边界与限制（同前版本）
- 禁止引入真实的网络流量抓包
- 禁止调用真实的大模型 API
- 所有数据来源于 `data/wifi_scenarios.json`
