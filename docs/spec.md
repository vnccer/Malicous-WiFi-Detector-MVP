# 恶意 WiFi 检测 MVP — 需求规格说明

---

## v1.0 需求规格说明

### 项目概述
本项目旨在构建一个基于 Agent-based 架构的 MVP，通过模拟分析 WiFi 网络特征，检测潜在的个人信息窃取风险，并向用户发出红/黄/绿灯直观预警。

### 用户角色
- **普通用户**：点击一键扫描，查看周边 WiFi 安全评估报告

### 核心功能
1. **模拟 WiFi 扫描**：从本地 JSON 文件加载预设 WiFi 场景数据
2. **AI Agent 诊断**：通过规则引擎模拟安全专家分析，输出风险等级和诊断报告
3. **可视化预警**：使用 Streamlit 展示红/黄/绿灯卡片式的安全分析结果

### 验收标准
- [ ] 用户点击"一键扫描"按钮后可看到 WiFi 列表
- [ ] 选择某个 WiFi 后展示包含风险等级、意图分析、安全建议的诊断报告
- [ ] 高风险 WiFi 以红色错误卡片展示，中风险以黄色警告展示，低风险以绿色成功卡片展示
- [ ] JSON 文件缺失或格式错误时有友好的错误提示

### 边界与限制
- 禁止引入真实的网络流量抓包
- 禁止调用真实的大模型 API（如 OpenAI, LangChain）
- 所有数据来源于 `data/wifi_scenarios.json`
- 界面文本与代码注释保持中文

## v2.0 需求规格说明

### 项目概述
本项目旨在构建一个基于 Agent-based 架构的 MVP，通过模拟分析 WiFi 网络特征，检测潜在的个人信息窃取风险，并向用户发出红/黄/绿灯直观预警。

**v2.0 基于用户反馈迭代**，在 v1.0 核心流程基础上增强视觉直观性、交互明确性和用户参与感。

### 用户角色
- **普通用户**：点击一键扫描，查看周边 WiFi 安全评估报告，提交使用反馈

### 核心功能

#### v1.0 保留功能
1. **模拟 WiFi 扫描**：从本地 JSON 文件加载预设 WiFi 场景数据
2. **AI Agent 诊断**：通过规则引擎模拟安全专家分析，输出风险等级和诊断报告
3. **可视化预警**：使用 Streamlit 展示红/黄/绿灯卡片式的安全分析结果

#### v2.0 新增功能
4. **风险排序**：WiFi 列表默认按风险等级从高到低排列，高风险置顶
5. **风险筛选**：提供 全部 / 🔴高风险 / 🟡中风险 / 🟢低风险 四个筛选按钮
6. **风险标签**：每个 WiFi 前显示红/黄/绿风险图标，信号强度图标，无需点开即可感知风险
7. **显式诊断触发**：选择 WiFi 后需点击「开始诊断」按钮，报告才会更新，交互意图更明确
8. **诊断原因标签**：报告卡片内展示彩色原因标签（如"🔓 开放网络""🕵️ DNS劫持风险""🔗 Portal认证"），一目了然
9. **同名热点检测**：当存在相同 SSID 的 WiFi 时，列表显示 ⚠️同名 警告标记，防止恶意热点伪装
10. **黑名单管理**：高风险 WiFi 可加入黑名单，在列表中统一管理
11. **用户反馈收集**：页面底部提供反馈输入框，用户提交的建议保存至本地文件
12. **信号强度可视化**：根据 dBm 值显示不同信号图标（优秀/良好/较弱）

### 验收标准
- [ ] 用户点击"一键扫描"按钮后可看到 WiFi 列表，**列表按风险从高到低排序**
- [ ] 每个 WiFi 条目显示🔴🟡🟢风险图标 + 信号强度图标 + 加密方式
- [ ] 存在同名 SSID 时，列表顶部显示 ⚠️ 警告，同名条目标注标记
- [ ] 点击筛选按钮（全部/高/中/低）可过滤对应风险等级的 WiFi
- [ ] 选择某个 WiFi 后点击「开始诊断」，展示完整诊断报告卡片
- [ ] 报告卡片包含：风险等级标题、诊断原因标签（彩色 pill）、意图分析、安全建议
- [ ] 高风险报告卡片下方显示「加入黑名单」按钮，可加入/移出黑名单
- [ ] 黑名单区域展示已标记的 WiFi 详细信息（SSID、MAC、信道、加密）
- [ ] 用户反馈区可输入文字并提交，提交后显示成功提示
- [ ] JSON 文件缺失或格式错误时有友好的错误提示

### 边界与限制
- 禁止引入真实的网络流量抓包
- 禁止调用真实的大模型 API（如 OpenAI, LangChain）
- 所有数据来源于 `data/wifi_scenarios.json`
- WiFi 唯一标识使用 MAC 地址（而非 SSID），避免同名热点覆盖
- 界面文本与代码注释保持中文
